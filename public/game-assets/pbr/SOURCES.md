# Environment assets

These files are used locally by the ruin scene and copied into the game / Toy builds.

- [Monastery Stone Floor](https://polyhaven.com/a/monastery_stone_floor): Amal Kumar, CC0. Original 2K diffuse and OpenGL normal JPEGs; original 1K packed AO/roughness/metal JPEG.
- [Sandstone Cracks](https://polyhaven.com/a/sandstone_cracks): Rob Tuytel, CC0. Original 1K diffuse, OpenGL normal and packed AO/roughness/metal JPEGs.
- [Kloppenheim 06 (Pure Sky)](https://polyhaven.com/a/kloppenheim_06_puresky): Greg Zaal and Jarod Guest, CC0. Original 1K HDR panorama used for the background and PMREM lighting.
- [Rock Face 01](https://polyhaven.com/a/rock_face_01): Dario Barresi, CC0. Original glTF with a shared binary buffer and original 1K textures. All five model files were checked against the MD5 values from the publisher's download metadata.

Texture files are unchanged. The courtyard, columns, masonry, arch, vegetation, sea and castle geometry / placement are part of this prototype. Existing card art and other game assets have their own provenance.

- [Leafy Grass](https://polyhaven.com/a/leafy_grass): Charlotte Baglioni, CC0. Original 1K diffuse, OpenGL normal and packed ARM JPEGs.
- [Pine Tree 01](https://polyhaven.com/a/pine_tree_01): photography by Rob Tuytel, modeling by Rico Cilliers, CC0. Original 1K twig diffuse JPEG, twig alpha PNG and bark diffuse JPEG. The published texture atlas is sampled by foliage mesh UVs; image files are unchanged. No full tree model is loaded.

The six new files were verified against the publisher’s MD5 download metadata. Rolling terrain, sparse grass, pine assembly and the old approach are authored scene geometry.
