# 星域决斗 · 本地可玩首版

横屏网页游戏，面向游戏王基础玩法的概念验证。界面中文，18 种基础卡加 8 种秘藏新卡，完整卡面采用英文版本的原始图片，配有中文名称、效果与操作说明。

## 启动

需要 Node.js 22.12+ 或 24+，推荐 Node.js 24/25。

```sh
npm ci
npm run build:game
npm run start:game
```

打开 `http://127.0.0.1:5175/game.html`。开发模式使用 `npm run dev:game`。端口可通过 `PORT` 指定。默认仅监听本机；同一局域网手机试玩时由开发者设置 `HOST=0.0.0.0`，手机连接电脑的局域网地址。两名玩家必须连接同一服务。当前没有公网部署。

新开空白标签页再输入网址，可建立另一名测试玩家。刷新当前标签页会恢复其游客身份；复制已有标签页可能复制会话并替换旧连接。昵称、战绩、解锁进度保存在服务端的 `work/duel-runtime/profiles.json`。关闭标签页会丢失该页的游客令牌；正式账户系统待后续接入。

## 已实现

- 大厅按当前战术展示代表卡，提供三个模式入口、四套不同构成的免费预组和可自由编辑的 40 张卡组。
- 人机：三节教学、三档练习、四个战术挑战，暂停、重开和操作提示。
- 在线匹配：真实双人 Socket.IO 对局，近期表现与新玩家分组，等待 60 秒可扩大范围或取消。匹配成功后双方准备，随机决定先手。
- 好友：六位房间码、加入错误反馈、卡组与准备状态、房主开始、解锁场景选择、结算再战。
- 服务器判定抽牌、召唤、祭品、攻守、攻击、魔法／陷阱、逆序连锁、伤害、弃牌和胜负。客户端只收到自己的手牌及对方公开状态。
- 联网回合 120 秒，响应 15 秒；响应超时不发动，回合超时判负。断线计时继续，60 秒内恢复同一对局；超时结算。投降需要二次确认。
- 匹配记录胜败，好友与人机不计匹配战绩。教学／挑战解锁卡背、冰蓝竞技场和紫焰召唤光环；下一局应用，无数值收益。
- Three.js 场地、实体卡片、镜头拖动、召唤光柱、旋转法阵、冲击环、碎片与攻击光弹；高星召唤镜头按等级触发，颜色按属性决定，适用于基础卡和获得的新卡。演出可跳过、关闭或减弱闪光；可选提示音与设备震动。
- 26 张高还原完整卡面用于手牌、图鉴、场上卡片和放大详情，白龙使用经典插画。操作面板显示实时中文效果和攻击力变化。

- 18 种实体怪兽模型覆盖全部基础与秘藏怪兽；栗子球有立体毛发和眼睛，战士有盔甲和武器，龙／恶魔有可动翼膜。古罗马石板平台、断柱、看台与暖色动漫遗迹背景形成统一场景。

## 四种战术路线

| 预组 | 核心打法 |
| --- | --- |
| 突击 · 节奏压制 | 低星展开、突进强化、保持场面；默认出战模板 |
| 秘法 · 魔法控场 | 地割与旋风处理阻碍，保留魔法、陷阱连锁 |
| 磐石 · 守备反击 | 2000 守备防线、栗子球和陷阱应对攻击 |
| 巨龙 · 上级压制 | 保护祭品，比较上级召唤收益；白龙只属于此路线 |

四套预组均为 40 张、每种至多 3 张，前三套不含白龙。预组仍使用经典小牌池，这些是不同资源分配的战术模板，不代表完整现代 OCG 主题卡组，也未经过竞技胜率校准。教学使用精灵剑士、战斧牛头人等讲解通用机制；挑战覆盖上级召唤、速攻突破、陷阱反击和墓地复活。上级挑战会根据所选预组调整目标怪兽。

## 秘藏召唤与新卡对战

大厅顶部“秘藏召唤”进入专属圣殿。单抽消耗 1 券、十连消耗 10 券；游客初始获得 30 张免费券，每日补给 10 张（UTC+8），教学首次完成 +3、挑战首次完成 +5。本版无付费购买。

演出依次经过触碰法阵蓄能、卡封碎裂、实体卡翻面、稀有光效与结果入藏。十连逐张揭晓，可跳过查看全部；离开或刷新不会丢失已保存结果，可查看上次召唤。触碰只影响视觉，不改变概率。可选音效、震动、减弱闪光。

卡池含 8 种新的通常怪兽，未发现卡以未知卡背展示；客户端按需接收自己获得或对战中公开的新卡元数据。基础概率 N 60%、R 28%、SR 10%、UR 2%；同稀有度等概率。每次十连至少 SR，连续 50 抽内必得 UR（取得 UR 后重新计数）。稀有度是本原型的分类，与实卡印刷版本无关。每种持有最多 3 张，多余卡转换幻尘：N 2、R 5、SR 20、UR 80；幻尘尚未开放兑换。

结果页点击“加入我的卡组”，先移除预组中的旧卡，再加入持有的新卡。保存时服务器校验恰好 40 张、每种最多 3 张、不超过持有量；自定义卡组可用于人机、在线匹配和好友切磋。卡牌属性固定，已获得卡片不因等级或外观增益。

## 操作

场地支持左右拖动调整视角，点击实体怪兽或脚下标签打开操作面板，“查看立体怪兽”可旋转和缩放模型。盖放怪兽只显示卡背，不展示模型。

手牌以拖拽出牌：将怪兽拖入前排、魔法或陷阱拖入后排盖放，合法落点会发光，松手完成放置。攻击召唤与守备盖放可提前切换；上级召唤在松手后确认祭品，复活魔法在松手后选择墓地目标。无落点的魔法可拖向场上目标或右侧发动区。无效区域、手势取消、断线或局面变化时卡牌回到手牌，不提交操作。轻点手牌仅查看详情；场上卡牌仍通过侧边面板进行攻击与效果操作。键盘可在手牌上按空格提起、方向键切换合法落点、回车放下、Esc 取消。攻击预览只按公开数值计算，未知盖牌不显示预测伤害。手机端关键按钮至少高 44 CSS 像素。发光手牌可以操作；左侧“场上卡牌”也可选择怪兽或盖牌。连锁响应栏显示触发动作和可发动卡牌；只有一个合法选项的效果可直接发动，或选择“不响应”。还有未攻击怪兽时切换阶段会出现原位提示。攻击需要先进入战斗阶段；首回合不能战斗。回合结束时手牌超过 6 张需选择弃牌。魔法／陷阱共有 5 个区域；盖放的陷阱与速攻魔法不能在盖放回合发动。双方无可发动卡片时自动跳过响应。

## 边界

这是浏览器可运行首版，尚未打包 iOS/Android。古罗马遗迹的石台、石柱与 18 种怪兽均为实体 3D 几何，具有物理材质、落地阴影、关节呼吸／翼动、召唤显形及攻击动作。当前模型是自制风格化原型，尚未达到原设计图的精细角色雕刻、纹理与完整骨骼动画品质；原生端和真机性能仍待后续开发。

规则是 `classic-strategies-v2` 固定小牌池，没有融合、仪式、同调、超量、灵摆、连接、额外卡组或现代 OCG 全部裁定。抽牌／准备阶段在无相关效果时合并展示。裂缝的最低攻击力同值时按最左区域结算；攻击目标被连锁移除时允许重新选择攻击。本版不复现完整攻击回卷裁定和全部伤害步骤。困难 AI 使用公开战场评估、祭品资源价值及守备选择，不读取对手隐藏卡；尚无深度搜索。

服务端对局保存在内存中，服务重启会终止未完成对局，战绩、外观、收藏、抽卡记录和自定义卡组保留。尚无正式账户、跨设备登录、观战、聊天、段位、赛季、锦标赛、反作弊运营或分布式部署。当前匹配无需人机补位；只有一位玩家时会持续等待。

## 校验

```sh
npm run check:runtime
npm run test:game
npm run build:game
```

保留了原始 mobile-app 模板的 28 个受保护文件。`/` 为模板中的竖屏引导入口，实际横屏游戏是 `/game.html`；生产服务直接引导至横屏入口。本轮 65 项游戏测试通过，覆盖四种预组、七个教学／挑战、属性召唤表现、服务器规则与真实双客户端通信，详见 `verification.md`；视觉证据与对照见 `design-qa.md`、`evidence/`。

## 文件

`src/Game.tsx`：界面与流程；`src/Arena.tsx`：3D 渲染；`src/monsterModels.ts`：18 种实体模型与动作；`src/ancientArena.ts`：遗迹建筑；`src/MonsterViewer.tsx`：可旋转模型近景；`server/engine.mjs`：规则／公开状态／AI；`server/index.mjs`：匹配、房间、会话与计时；`server/decks.json`：固定卡组；`src/cards.json`：基础卡；`server/hidden-cards.json`：秘藏卡池；`server/gacha.mjs`：抽卡与持有校验；`src/Summon.tsx` / `src/GachaScene.tsx`：召唤流程和 3D 演出；`src/DeckEditor.tsx`：组卡；`public/game-assets/`：自托管素材。

## 素材来源

完整卡面和裁剪插画从 [YGOPRODeck API](https://ygoprodeck.com/api-guide/) 缓存到本地，不在运行时请求或热链接远程图片。卡牌图像及角色属于其原权利方，保留图片中的版权标记；本项目是本地原型。旧竞技场和怪兽精灵、古罗马遗迹背景、原创决斗者头像、蓝红 HUD 边框、光环、地板、召唤圣殿与自定义卡背由图像生成制作，用于本项目视觉验证。正式产品的授权与完整资产制作需另行落实。

## Toy 适配版

`npm run build:toy` 生成 `dist/toy/index.html`，使用相对资源路径，可在 Toy 的子路径下运行。此版本无需 Node.js 服务，可游玩人机教学／练习／挑战、召唤和组卡；收藏存在当前浏览器本地，不与联网版游客账号同步。实时匹配与好友切磋需要完整服务器版，静态试玩会给出说明，不模拟真人 PK。静态文件里的卡池可被开发者工具读取，因此秘藏是游戏内探索体验；公平联网对局仍采用服务器隐藏信息。
