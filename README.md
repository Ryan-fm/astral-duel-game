# 游戏王：遗迹决斗 · 本地可玩首版

**版权状态：作者已批准公开发布的非官方原型，尚未取得游戏王相关素材的 IP 发布授权。** [全局审查与整改路线](../copyright-review/README.md)记录了素材来源和待处理项。免费、署名、AI 重画或平台审核不替代 IP 授权；本构建不代表已清权。

横屏网页游戏，面向游戏王基础玩法的概念验证。界面中文，30 种基础卡与 15 种本期 DM 秘藏卡，另保留 1 种旧版后期卡，完整卡面采用英文版本的原始图片，配有中文名称、效果与操作说明。

打开游戏先显示用户指定的青眼白龙入场图，点击画面或用 Enter／空格进入决斗大厅。原图完整展示，桌面与手机可用；减弱动态设置可关闭入场淡入。游戏连接和场景在进入后才启动，不会在开场图后运行对局。

## 启动

需要 Node.js 22.12+ 或 24+，推荐 Node.js 24/25。

```sh
npm ci
npm run build:game
npm run start:game
```

打开 `http://127.0.0.1:5175/game.html`。开发模式使用 `npm run dev:game`。端口可通过 `PORT` 指定。默认仅监听本机；同一局域网手机试玩时由开发者设置 `HOST=0.0.0.0`，手机连接电脑的局域网地址。两名玩家必须连接同一服务。当前公网入口为 [游戏王：遗迹决斗](https://astral-duel-game.vercel.app/)。

新开空白标签页再输入网址，可建立另一名测试玩家。刷新当前标签页会恢复其游客身份；复制已有标签页可能复制会话并替换旧连接。昵称、战绩、解锁进度保存在服务端的 `work/duel-runtime/profiles.json`。关闭标签页会丢失该页的游客令牌；正式账户系统待后续接入。

## 已实现

- 大厅按当前战术展示代表卡，提供三个模式入口、六套不同构成的免费预组和可自由编辑的 40 张主卡组与 0–15 张额外卡组。
- 人机：五节教学、三档练习、四个战术挑战，暂停、重开和操作提示。
- 在线匹配：真实双人 Socket.IO 对局，近期表现与新玩家分组，等待 60 秒可扩大范围或取消。匹配成功后双方准备，随机决定先手。
- 好友：六位房间码、加入错误反馈、卡组与准备状态、房主开始、解锁场景选择、结算再战。
- 服务器判定抽牌、召唤、祭品、攻守、攻击、魔法／陷阱、逆序连锁、伤害、弃牌和胜负。客户端只收到自己的手牌及对方公开状态。
- 联网回合 120 秒，响应 15 秒；响应超时不发动，回合超时判负。断线计时继续，60 秒内恢复同一对局；超时结算。投降需要二次确认。
- 匹配记录胜败，好友与人机不计匹配战绩。教学／挑战解锁卡背、冰蓝竞技场和紫焰召唤光环；下一局应用，无数值收益。
- Three.js 场地、实体卡片、镜头拖动、召唤光柱、旋转法阵、冲击环、碎片与攻击光弹；高星召唤镜头按等级触发，颜色按属性决定，适用于基础卡和获得的新卡。演出可跳过、关闭或减弱闪光；可选提示音与设备震动。
- 46 张高还原完整卡面用于手牌、图鉴、场上卡片和放大详情，白龙使用经典插画。操作面板显示实时中文效果和攻击力变化。

- 战斗可读性：公开魔法／陷阱发动依次展示约 4 秒，并保留最近发动记录；连锁响应显示来源卡牌，说明支持标准／大字。服务器响应时钟独立运行。
- 场上盖牌改为小型中性徽标，公开后才显示魔法／陷阱颜色；怪兽保留攻守数值，相邻标记按透视留出点击间距。
- 手牌使用放大的浅扇形错叠，选中抬起转正并显示青色边框；拖出出牌、轻点详情和键盘操作保留，小屏超量手牌可翻组。
- 遗迹渲染增加自然方向光、接触阴影与深度雾，支持自动／高／低画质及性能降级；怪兽延续真实卡面和既有立绘。

- 两种免费场景：古罗马遗迹与霓虹都市。人机入口、外观设置和好友房间可选择；偏好保存，下局生效，好友双方使用房主选择的同一场景。场上怪兽恢复为前一版的完整卡面／青眼与黑魔导立绘，保留召唤法阵与攻击特效。

## 六种战术路线

| 预组 | 核心打法 |
| --- | --- |
| 突击 · 节奏压制 | 低星展开、突进强化、保持场面；默认出战模板 |
| 秘法 · 魔法控场 | 地割与旋风处理阻碍，保留魔法、陷阱连锁 |
| 磐石 · 守备反击 | 2000 守备防线、栗子球和陷阱应对攻击 |
| 巨龙 · 上级压制 | 保护祭品，比较上级召唤收益；白龙只属于此路线 |
| 融合 · 龙骑士之约 | 指定素材＋融合魔法，额外卡组 9 张，盖亚／炎之剑士／黑魔龙 |
| 仪式 · 混沌降临 | 手／场等级解放＋对应仪式魔法，混沌战士／混沌黑魔术师 |

六套预组主卡组均为 40 张、每种至多 3 张，前三套不含白龙。预组仍使用经典小牌池，这些是不同资源分配的战术模板，不代表完整现代 OCG 主题卡组，也未经过竞技胜率校准。教学使用精灵剑士、战斧牛头人等讲解通用机制；挑战覆盖上级召唤、速攻突破、陷阱反击和墓地复活。上级挑战会根据所选预组调整目标怪兽。

## 秘藏召唤与新卡对战

大厅顶部“秘藏召唤”进入专属圣殿。单抽消耗 1 券、十连消耗 10 券；游客初始获得 30 张免费券，每日补给 10 张（UTC+8），教学首次完成 +3、挑战首次完成 +5。本版无付费购买。

演出依次经过触碰法阵蓄能、卡封碎裂、实体卡翻面、稀有光效与结果入藏。十连逐张揭晓，可跳过查看全部；云端／服务器保存成功后，离开或刷新不会丢失结果；本地 Toy 游客仅保留本次页面进度，可查看上次召唤。触碰只影响视觉，不改变概率。可选音效、震动、减弱闪光。

本期抽卡池含 15 种 DM 经典卡（含陨石黑龙融合怪兽），此前已拥有的亚历山大龙继续可用但不再在本期抽取，未发现卡以未知卡背展示；客户端按需接收自己获得或对战中公开的新卡元数据。基础概率 N 60%、R 28%、SR 10%、UR 2%；同稀有度等概率。每次十连至少 SR，连续 50 抽内必得 UR（取得 UR 后重新计数）。稀有度是本原型的分类，与实卡印刷版本无关。每种持有最多 3 张，多余卡转换幻尘：N 2、R 5、SR 20、UR 80；幻尘尚未开放兑换。

结果页点击“加入我的卡组”，先移除预组中的旧卡，再加入持有的新卡。保存时服务器校验恰好 40 张、每种最多 3 张、不超过持有量；自定义卡组可用于人机、在线匹配和好友切磋。卡牌属性固定，已获得卡片不因等级或外观增益。

## 操作

场地支持左右拖动调整观察角度，点击怪兽卡面、立绘或脚下标签打开操作面板。盖放怪兽只显示卡背，不展示立绘；已移除程序建模怪兽及模型查看入口。

手牌向上拖出到战场即可出牌，不必对准具体卡位。越过手牌边界后显示金色就绪反馈和自动落位预告；松手才提交操作，拖回手牌取消。怪兽自动安排合法位置；攻击召唤与守备盖放可提前切换。魔法优先发动，无合法发动时可盖放；也可在卡牌详情中明确选择盖放再拖出。陷阱默认盖放。目标、祭品、融合和仪式素材在松手后继续选择；自动落位不会删减满场时的祭品组合。目标魔法也可直接拖向合法场上目标。无效区域、手势取消、断线或局面变化时卡牌回到手牌，不提交操作。轻点手牌仅查看详情；场上卡牌仍通过侧边面板进行攻击与效果操作。键盘可在手牌上按空格提起、回车自动出牌、Esc 收回；方向键仍可切换合法落点和目标。攻击预览只按公开数值计算，未知盖牌不显示预测伤害。手机端关键按钮至少高 44 CSS 像素。发光手牌可以操作；左侧“场上卡牌”也可选择怪兽或盖牌。连锁响应栏显示触发动作和可发动卡牌；只有一个合法选项的效果可直接发动，或选择“不响应”。还有未攻击怪兽时切换阶段会出现原位提示。攻击需要先进入战斗阶段；首回合不能战斗。回合结束时手牌超过 6 张需选择弃牌。魔法／陷阱共有 5 个区域；盖放的陷阱与速攻魔法不能在盖放回合发动。双方无可发动卡片时自动跳过响应。

战斗界面默认展开战场，只保留生命值、阶段、计时与攻守数值。选中卡牌后才出现紧凑的操作面板、目标与伤害预估；卡牌效果和教学目标可按需展开，完整记录仍可从左侧查看。手机横屏的确认攻击、召唤表示、关闭和连锁响应按钮均至少高 44 CSS 像素。

## 边界

这是浏览器可运行首版，尚未打包 iOS/Android。按作者反馈，场上怪兽已回退到卡面与立绘精灵；当前不提供体积角色模型。默认王国遗迹使用连贯的 3D 庭院、PBR 石材、扫描岩壁、岛屿地形、树林和通往城堡的道路；都市保留插画地面与空间卡位。原生端和真机性能仍待后续开发。

规则是 `classic-dm-v3`，已支持 4 种指定素材融合、2 种指定仪式召唤和额外卡组。融合素材来自自己的手牌／场上，仪式从手牌召唤并解放足够总等级的手牌／场上怪兽，两者都不占通常召唤。融合／仪式怪兽须先正规召唤才能从墓地复活。此版是 DM 动画主题精选，非完整历史 OCG 卡表、禁限表或全裁定模拟；未加入同调、超量、灵摆、连接。原型在发动时确认融合／仪式的素材选择，结算时重新校验；若选中素材变化，则不消耗剩余素材、不召唤。这与完整 OCG 在效果结算时选择素材的流程有差异。抽牌／准备阶段在无相关效果时合并展示。裂缝的最低攻击力同值时按最左区域结算；攻击目标被连锁移除时允许重新选择攻击。本版不复现完整攻击回卷裁定和全部伤害步骤。困难 AI 使用公开战场评估、祭品资源价值及守备选择，不读取对手隐藏卡；尚无深度搜索。

## 素材与发行检查

`legal/asset-rights.json` 覆盖 public 内全部文件及 SHA-256；旧 `asset-manifest.csv` 是早期来源记录，不是许可证明或完整现状清单。`public/legal/ASSET-NOTICES.txt` 提供来源说明，`public/legal/THIRD-PARTY-NOTICES.txt` 收录生产依赖的许可全文。依赖更新后运行 `npm run notices:collect`，并重新复核台账。

`npm run check:rights` 是发行证据检查；当前因 IP／其他许可待确认而按预期返回非零。`npm run release:toy`／`release:game` 先运行它再构建。普通 build 命令只用于本地开发检查，不表示许可完成。脚本不能阻止手工上传，也不是法律意见或用户发布确认。作者本轮已明确授权公网部署及 PR／Toy 更新。`release:prototype:game` / `release:prototype:toy` 使用独立原型发布检查，固定素材台账与权利策略的摘要；严格发行检查仍返回未清权，未修改 IP 许可结论。Toy 最终审核按预览确认流程提交。

服务端房间、对局、计时、收藏和结算已持久化：本地使用文件，联机部署使用 Redis 原子提交，重启后按原截止时间恢复或补结算。完整服务器版使用游客令牌；Toy 可在账号云存档保管服务器凭证，仍待真实跨设备验收。尚无观战、聊天、段位、赛季、锦标赛或反作弊运营。当前匹配无需人机补位；只有一位玩家时会持续等待。

## Toy 适配版

`npm run build:toy` 生成 `dist/toy/index.html`，使用相对资源路径，可在 Toy 的子路径下运行。此版本无需 Node.js 服务，可游玩人机教学／练习／挑战、召唤和组卡；在 B站 Toy 环境按官方 SDK 使用当前登录账号的云存档；主／额外卡组、收藏、券数、外观和挑战进度一起保存。读取失败时阻止覆盖，可主动切换游客；本地静态预览仅使用页面内存，不保存进度。旧本机存档可在空云存档时主动导入。完整版服务器游客账号与 B站云存档不互通。实时匹配与好友切磋需要完整服务器版，静态试玩会给出说明，不模拟真人 PK。静态文件里的卡池可被开发者工具读取，因此秘藏是游戏内探索体验；公平联网对局仍采用服务器隐藏信息。

## 账号、排行榜与语音召唤

使用 [B站官方 Toy SDK](https://www.bilibili.com/toy/publish/sdk) 的 getUserProfile、getCloudStorage / setCloudStorage、submitScore / getRankList / getMyRank 和 requestMicrophone / stopMedia。Toy OpenID 不充当服务器身份凭据；云存档使用 UTF-8 分片、双代索引与校验和，结果未确认时要求重新读取后继续，不自动以空存档覆盖。不要多个设备同时编辑，平台接口没有本项目可用的版本比较写入。

排行榜记录四个经典挑战的最佳成绩之和，重复通关不叠加。完整版另有服务器结算的匹配胜场榜。Toy 首次参加榜单需玩家点击并经过平台授权；它是客户端休闲成绩展示，不具备服务器反作弊保障。缓存榜单、仅在结算／保存时写入，遇到 307044 指数退避，不写死共享 API 配额。

左侧麦克风入口支持声量唤醒（选择可召唤怪兽后以本地声量触发）和浏览器支持时的卡名识别。Toy 麦克风 SDK 只提供音轨，不提供文字识别。语音只执行服务器／规则引擎投影的合法操作，融合、仪式、上级召唤仍手动确认素材／祭品。仅点击后采集；关闭、局面改变、后台、结束或拒绝权限会停止音轨。不保存音频；浏览器卡名识别可能将音频发送给浏览器提供的识别服务。

平台能力完成本地实现与模拟 SDK 测试；历史 Toy 预览不代表本轮联机版本已上传。真实平台账号、跨设备恢复及麦克风设备仍待正式环境验收。

## 联机接入与免费降级

Toy 版现可通过联机入口连接独立对战服务，支持在线匹配、好友房间及联机收藏。已有 Toy 存档保留；联机抽卡和卡组由服务器校验。Toy 平台可用云存档保存服务器随机签发的身份凭证，不把 toyOpenId 当作认证。

`server/app.mjs` 提供可复用 Socket.IO 服务；`api/duel.mjs` 与 `vercel.json` 提供 Vercel 入口。配置模板在 `deploy/online.env.example`。联机模式必须配置持久化 Redis，可以共用现有免费库；`DUEL_REDIS_SHARED=1` 时必须显式设置本游戏命名空间，生产／预览分开。支持标准 Upstash 凭证或 Vercel `DUEL_KV_REST_API_URL` / `DUEL_KV_REST_API_TOKEN` 完整配对，密钥仅用于服务端。缺少配置会拒绝启动，不将真人对局回退到内存。

联机存储当前使用全局版本 + Redis Lua CAS 提交整个小规模测试世界，对局、收藏、去重和结算一起提交。部署配置采用活跃轮询 1500ms、闲置轮询 10000ms，无连接不轮询，失败时退避。共享库共用免费额度，命名空间不提供键级权限隔离。它面向首版小规模试玩；大规模上线前须拆分每局状态、队列和用户存档并做容量测试。没有活跃实例时，截止时间保留，下一次请求按原截止时间补结算；可使用鉴权 `/api/duel/tick` 接入外部定时服务。

不使用 Redis 时运行 `npm run build:solo`，生成 `dist/solo/game.html`；Toy 使用 `npm run build:toy:solo`，生成 `dist/toy/index.html`。规则直接在浏览器运行，人机、抽卡、收藏、组卡保留，匹配／好友入口关闭。Toy 正式环境仍接账号云存档及挑战排行榜；普通静态预览只在页面内存暂存，刷新不保留。服务端也可配置 `DUEL_ONLINE_ENABLED=0` 提供关闭状态而不初始化 Redis。联机入口在连接前检查可用性，失败不覆盖原 Toy 存档。

详细验证与部署步骤见 [免费资源与部署记录](../online-pk-review/DEPLOYMENT.md)。Vercel Hobby 公网服务已部署并共用现有免费库。真实 HTTPS/WSS 已验证匹配、好友 PK、隐藏手牌、请求去重、恢复同局及五分钟函数轮换后的自动重连。Toy 包使用该公网地址；预览页因没有作品 ID 使用临时身份，正式页面继续使用账号云凭证。当前清权问题仍记录为未解除。


Toy 发布兼容性：`prepare-toy-build.mjs` 将扫描岩壁的 `.gltf` 以字节相同的 `.json` 别名分发，并保留同目录的二进制与纹理依赖，避免 Toy 预览对 `.gltf` 返回 404。公网版仍使用原始资产。联网 Toy 包需同时设置 `VITE_DUEL_SERVER_URL=https://astral-duel-game.vercel.app` 与 `VITE_DUEL_SOCKET_PATH=/api/duel/socket.io`。
