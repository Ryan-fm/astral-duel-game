# Blender character studies — checkpoint 2026-10-26

These are editable design studies. Their visual quality has not been approved for production; the battle game still uses card/cutout monsters.

- `blue-eyes/`: displayed v006 head/jaw study, editable Blender scene, animated GLB, six clips and review renders.
- `blue-eyes/iterations/v007/`: unfinished material/silhouette pass from 2026-10-26, including its Blender source, packed texture images and GLB. This is archived work in progress, not the default preview.
- `flame-wingman/`: earlier editable hero study and animated GLB.
- `preview/`: portable Three.js review page and locally vendored MIT runtime.

From the repository root run `python3 -m http.server 5203 --directory art/character-studies`, then open `http://127.0.0.1:5203/preview/?model=blue-eyes`.

The public game build does not copy this directory. No deployment, Toy update, production model replacement or IP-clearance claim is made by this checkpoint.

The Blue-Eyes geometry is locally authored using the classic character as a visual reference, including https://tamashiiweb.com/item/14516/ . Game/character rights records remain unresolved in the repository legal inventory. See the vendored Three.js license under `preview/vendor/`.
